# 第八轮定点复测

本次是同一模拟潜在用户对修订后的真实界面证据复核，不是新一轮真人研究，也不是完整流程重跑。主线程重置虚构样例、操作并捕获原始 AX/截图；我阅读三组证据并独立判断，未读实现。初测原文保留在 usability-round8-initial.md。

证据均在 evidence/round8/，每组包含 .txt 和 .png。

| 初测问题 | 本次可见证据 | 判定 |
| --- | --- | --- |
| 新问题与旧回执混在一起 | retest-01-new-question：当前问题明确“尚未提交”；按钮为“仅查已接入记录”，详情改为“查看本地查证范围（不发送）”。此前请求另折叠显示“仍在等待解释”及 10 秒/预算的问题摘要 | 当前样例已解决归属混淆，不需靠记忆猜哪一条已提交 |
| 本地查询掩盖旧请求待回复 | retest-02-independent-history：当前本地查证显示独立时间、问题；更早记录保留 code 只读通道、时间、原问题及“此请求尚未返回解释”。侧栏仍有“核实待回复”。retest-03 刷新后的折叠摘要仍说明有请求待解释 | 当前样例已解决。未验证多个旧请求、实际答复乱序返回 |
| 仅显示相关背景却说已定位所问依据 | retest-02：改为“已显示本地记录 · 问题尚未核实”，并说明未确认能回答问题、没有向原 agent 发送 | 过度成功表述已解决；问题本身仍未得到答案，本地检索价值尚未验证 |
| 重新采用后残留撤销提示 | retest-03-no-stale-undo：主线程重走 3→2、撤销、再替换并刷新后的页面，已处理 1 处，正文是最多 2 次且保留汇报要求；完整 AX 与截图无旧撤销提示 | 此定点场景已解决。中间操作由主线程报告，最终可见状态由我核对；不是再次重跑初测两句完整路径 |

没有在这三组证据发现新的阻断。状态归属改善有实际意义：我能分别看懂“新问题未提交”“本地只显示记录”“旧 agent 请求还没答复”，无需把几段文案拼成一段记忆。

残余成本仍在：核实卡置于修复草稿之前，即使折叠旧记录，仍占显著高度；本地查询给出的是来源展示，用户还需自行核实。当前样例可以接受，不能推断几十个工作、多条请求下也轻松。下一步应以真实记录的恢复任务观察这个成本，而非再用本样例反复证明点击可达。

边界：未验证真实只读能力强制、实际 agent 发送与接受、检索回答准确性、全文语义覆盖、任意编辑后的撤销、跨设备持久化、真实人工时间/注意力收益或付费意愿。本地 UI 的明确限制不等于实际权限隔离。修订后的完整最终修复交接未在本次定点复核重跑；初测已跑通的交接证据仅属于当时版本。
