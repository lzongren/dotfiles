# Devbox product exploration

This directory contains the English edition of PRFAQ **0.8**, dated October 18, 2026, and the evidence for its latest simulated review. The companion [interactive prototype](../../prototypes/devbox-attention/README.md) is version **0.7**.

- [English PRFAQ](PRFAQ-v0.8.en.md) is the reviewable source, with all 27 customer/internal questions and the trial, cost, provenance, authorization, and enrollment rules.
- [Word edition](PRFAQ-v0.8.en.docx) contains the same English text for document review.
- [Review evidence](evidence/README.md) distinguishes initial scenario testing, targeted retests, and simulated acceptance of the plan.

The English edition consolidates repeated appendix material from the Chinese v0.8 document without changing its candidate value or payment rules. The only additional clarification is that a trial extension requires its own agreed effort and cost terms, as stated in the final review. A source fingerprint is recorded in `provenance.json`.

No real trial, customer enrollment, integration readiness, payment, or renewal is claimed. The original Chinese prototype UI is preserved. This package does not alter the production `web/` app.
